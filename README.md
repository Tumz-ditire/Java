# Java Learning Projects

Welcome to my Java learning repository! This project showcases my Java programming journey with practical GUI applications developed using **Eclipse IDE for Java Developers**.

## Projects Included

### 1. Login Form
A GUI application featuring a login screen for user authentication. This project demonstrates my understanding of Java GUI components and user interface design.

**Developed with**: Eclipse IDE for Java Developers

### 2. Order Form
An interactive order form application for a construction company that allows customers to configure and order custom homes. Users can select from different house models, choose the number of bedrooms, and select garage options with dynamic pricing calculations.

**Developed with**: Eclipse IDE for Java Developers

## About This Repository

- Event handling and user interaction
- Business logic and calculations
- Application architecture and design patterns
